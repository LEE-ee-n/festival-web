# Festibom 8월 카드뉴스 초안 플러그인

프로덕션 배포 후 Figma Desktop에서 아래 순서로 설치한다.

1. 카드뉴스 템플릿 파일을 연다.
2. `Plugins` → `Development` → `Import plugin from manifest...`를 누른다.
3. 이 폴더의 `manifest.json`을 선택한다.
4. Figma에서 `Plugins` → `Development` → `Festibom 8월 카드뉴스 초안`을 실행한다.
5. `8월 초안 생성`을 누른 뒤, 오른쪽에 생성된 카드들을 검수한다.

필수 템플릿 이름은 다음과 같다.

- `cover_template`
- `festival_card_template`
- `festival_list_template`
- `closing_template`

레이어 이름이 다르면 플러그인은 해당 이름을 오류로 보여 주고, 원본 템플릿은 수정하지 않는다.
