# ADR 0001: Expo WebView 기반 모바일 앱

- 상태: 승인
- 결정일: 2026-08-11

## 배경

Festibom은 Next.js 웹과 Supabase 회원·RLS·베타 이용권 체계가 이미 운영 중이다. Android 앱을 별도 네이티브 화면으로 다시 만들면 같은 기능과 권한을 이중 관리하게 된다.

## 결정

기존 운영 웹을 `Expo + React Native WebView` 앱에서 표시하는 하이브리드 구조를 사용한다. 앱은 네이티브 하단 메뉴, 시스템 Google 로그인, 푸시 알림, 딥링크, 일정 이미지 저장·공유를 담당한다. 웹과 앱은 같은 Supabase 회원·데이터·RLS·서비스 이용권을 사용한다.

앱 환경 표시는 UI 간소화에만 사용하며 권한 판정에는 사용하지 않는다. 관리자 화면, 결제, iOS는 Android 1차 범위에서 제외한다.

## 결과

- 기존 웹 기능을 단일 원본으로 유지한다.
- 앱 고유 기능은 검증된 웹-앱 메시지 계약으로만 연결한다.
- 앱에서도 RLS와 관리자 TOTP를 우회하지 않는다.
- Expo·Firebase·Play Console 설정 전에는 코드 검증과 실제 배포 검증을 구분한다.
