# [추가 수정 완료·화면 확인 대기] Instagram URL 관리자·공개 화면 최종 연결

## 목적과 완료 조건

- 축제 공식 홈페이지와 공식 Instagram 계정 URL을 관리자 화면에서 각각 확인·수정·저장할 수 있다.
- 신규 후보, 기존 수정 작업함, 축제 관리, 감사 로그에서 Instagram URL 흐름이 빠지지 않는다.
- 공개 축제 상세에서 기존 `공식 홈페이지` 버튼은 유지하고, 그 바로 위 줄에 별도 `인스타그램` 버튼을 추가한다.

## 확정 범위

- `/admin/festival-candidates`: 기본정보에 공식 Instagram URL 입력·검토
- `/admin/festival-updates`: 기존 값과 새 Instagram URL 비교·선택·최종 반영
- `/admin/festivals/[id]/lineup`: 기본정보에 공식 Instagram URL 입력·저장
- `/admin/audit-logs`: Instagram URL 변경명을 별도 표시
- 공개 상세 드로어와 독립 상세 페이지: 기존 공식 홈페이지 버튼 위에 별도 전체 너비 인스타그램 버튼 추가
- 관련 저장 흐름, 타입, 테스트와 문서 회귀 확인

## 제외 범위

- Instagram 외 다른 SNS 추가
- 기존 축제 Instagram URL 일괄 입력
- 공식 계정 자동 판정
- 운영 배포 실행

## 예상 수정 파일·데이터 흐름

- 관리자 후보·기존 수정·축제 기본정보 컴포넌트
- 감사 변경명 매핑
- `components/festival/FestivalOfficialLink.tsx`
- `app/festival/[id]/page.tsx`
- 관련 테스트와 `PROJECT_STATUS.md`

관리자가 `instagram_url`을 검토·저장하면 `festivals.instagram_url`에 반영되고, 공개 화면은 값이 있을 때 Instagram 버튼을 홈페이지 버튼 위에 표시한다.

## 작업 순서

1. 네 관리자 URL의 로컬 코드에서 입력·비교·저장·감사 표시 연결을 각각 확인한다.
2. 빠진 연결이 있으면 기존 공통 흐름을 확장한다.
3. 공개 상세 두 경로에서 기존 공식 홈페이지 버튼 위에 인스타그램 버튼을 별도 줄로 추가한다.
4. 관련 테스트, 타입 검사, 린트를 실행한다.
5. localhost 화면을 확인하고 운영 배포 전 상태를 문서화한다.

## 회귀 위험과 검증 방법

- `official_url`, `instagram_url`, 수집 출처 `source_url`이 서로 덮어쓰지 않는지 확인한다.
- Instagram URL이 비어 있으면 버튼을 숨기고 홈페이지 버튼은 정상 유지한다.
- 두 URL이 모두 있으면 인스타그램 버튼이 별도 윗줄, 공식 홈페이지 버튼이 아랫줄에 표시되는지 확인한다.
- 신규 후보와 기존 수정 저장 흐름을 분리한 기존 규칙을 유지한다.
- 관련 단위 테스트, 타입 검사, 변경 파일 ESLint와 localhost PC·모바일 화면을 확인한다.

## 후속 개선점

- 운영 배포 후 네 관리자 URL과 공개 상세에서 실제 데이터로 최종 확인한다.

## 구현 결과

- 신규 후보의 공식 Instagram 입력, 기존 수정 작업함의 비교·선택·반영, 축제 관리 기본정보 저장, 감사 로그 변경명 연결을 로컬 코드에서 확인했다.
- 공개 상세 드로어와 독립 상세 페이지에서 기존 공식 홈페이지 버튼 바로 위에 별도 전체 너비 `인스타그램` 버튼을 표시하도록 변경했다.
- Instagram URL이 없으면 인스타그램 버튼만 숨기고 기존 공식 홈페이지 버튼은 유지한다.
- 전체 테스트 156개, 타입 검사와 관련 파일 ESLint가 통과했다.
- localhost 개발 서버 기동은 확인했지만 브라우저 정책이 localhost 접근을 차단해 실제 PC·모바일 렌더링 확인은 남아 있다.

## 관리자 URL 표시 순서 추가 수정 계획

- 관리자 화면의 두 URL 표시 순서를 공개 상세와 동일한 `공식 Instagram → 공식 홈페이지`로 통일한다.
- 신규 후보 기본정보는 URL 필드 배열 순서를 바꿔 Instagram을 먼저 표시한다.
- 신규·기존 페스티벌 관리가 공통으로 사용하는 기본정보 화면에서는 Instagram 입력을 공식 홈페이지 바로 위로 이동한다.
- 기존 수정 작업함은 공식 홈페이지를 자동 변경 대상으로 삼지 않는 기존 규칙을 유지하므로 Instagram 단독 비교 표시를 변경하지 않는다.
- 감사 로그는 입력 폼이 아니므로 변경명 표시만 유지한다.
- 저장 값, 검증, DB 구조와 공개 상세 버튼 순서는 변경하지 않는다.
- 전체 테스트, 타입 검사와 해당 파일 ESLint 후 관리자 화면 실제 확인을 구분해 기록한다.

## 관리자 URL 표시 순서 추가 수정 결과

- 신규 후보 기본정보 URL 필드를 `공식 Instagram → 공식 홈페이지 → 대표 썸네일 URL` 순서로 변경했다.
- 신규·기존 페스티벌 관리 공통 기본정보에서 `공식 Instagram → 공식 홈페이지 → 무료·유료/진행 상태 → 공개 승인 상태` 순서로 변경했다.
- 축제 ID와 관계없이 공통 컴포넌트를 사용하는 모든 페스티벌 관리 화면에 적용된다.
- 기존 수정 작업함의 Instagram 단독 비교, 감사 로그 변경명과 공개 상세 순서는 유지했다.
- 전체 테스트 160개, 타입 검사와 변경 파일 ESLint가 통과했다.
- localhost 관리자 화면의 실제 순서 확인은 남아 있다.
