# [구현 완료·화면 확인 필요] PC 달력 휠 세로 스크롤 차단

## 목적과 완료 조건

- PC에서 달력 위로 마우스 휠을 돌리면 월만 이동하고 페이지가 푸터 방향으로 내려가지 않는다.
- Ctrl+휠 확대·축소, 가로 휠과 모바일 터치는 기존 동작을 유지한다.

## 원인

- 현재 React `onWheel`에서 `preventDefault()`를 호출하지만 브라우저의 수동 이벤트 처리 방식 때문에 기본 세로 스크롤이 함께 발생할 수 있다.
- 푸터가 추가되면서 페이지에 실제 세로 스크롤 영역이 생겨 문제가 눈에 보이기 시작했다.

## 수정 범위

- `components/Calendar.tsx`
- 달력 영역에 `{ passive: false }`인 네이티브 wheel 이벤트를 연결한다.
- 기존 월 이동 임계값 80, 잠금시간 450ms는 유지한다.

## 제외 범위

- 푸터 숨김 또는 삭제
- 모바일 스와이프 감도 변경
- 달력·푸터 높이 변경

## 검증

- [완료] 린트
- [완료] 전체 테스트 138건
- [차단] 타입 검사: 병행 작업 중 변경된 `CalendarDay` 타입과 `CalendarGrid` 사이의 기존 불일치로 중단
- [대기] localhost PC에서 달력 위 휠 시 월 이동과 페이지 위치 고정 확인
- [대기] 달력 밖에서 휠을 돌리면 일반 페이지 스크롤이 가능한지 확인

## 실제 결과

- React `onWheel`을 제거하고 달력 요소에 `{ passive: false }` 네이티브 wheel 이벤트를 연결했다.
- 달력 위 세로 휠은 기본 페이지 스크롤을 차단한 뒤 기존 임계값과 잠금시간으로 월을 이동한다.
- Ctrl+휠, 가로 휠과 굵은 포인터 환경은 차단하지 않는다.
