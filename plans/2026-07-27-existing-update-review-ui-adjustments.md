# [완료] 기존 페스티벌 수정 검토 UI 보완 계획

- 작성일: 2026-07-27
- 상태: 코드 구현 및 자동 검증 완료 · 실제 화면 확인 대기
- 승인일: 2026-07-27
- 대상: `/admin/festivals/import-json?festivalId=...&updateDraftId=...`
- DB 변경: 없음

## 목적과 완료 조건

- 각 단계의 정보 우선순위와 버튼 위치를 통일한다.
- 타임테이블 변경이 감지됐지만 선택하지 않아 최종 반영이 0건이 되는 문제를 화면에서 명확하게 해결한다.

## 확정 범위

### 2단계 아티스트 최종 확정

- 아티스트 항목의 연한 slate·보라색 배경을 제거한다.
- 흰색 배경과 회색 테두리만 사용한다.
- 기존 아티스트와 추가 아티스트 구분 문구는 유지한다.

### 3·4단계 비교표

- `새 값/새 일정`을 `현재 값/현재 일정`보다 앞에 표시한다.
- PC 열 순서와 모바일 세로 표시 순서를 모두 다음처럼 바꾼다.
  - 상태
  - 항목 또는 아티스트
  - 새 값 또는 새 일정
  - 현재 값 또는 현재 일정
  - 선택

### 4단계 일괄 선택

- 시간 변경은 이미 정상 감지되고 있으므로 비교 로직은 변경하지 않는다.
- 표 상단에 `표시된 변경 전체 반영`과 `전체 현재값 유지` 버튼을 추가한다.
- 자동으로 반영을 선택하지 않는다. 관리자가 전체 또는 개별 선택한 항목만 반영한다.
- 반영할 항목이 0건인 상태에서 다음 단계로 이동하면 선택이 없다는 안내를 표시한다.

### 5단계 최종 확정

- 요약 박스 안의 `페스티벌 수정 최종 확정` 버튼을 제거한다.
- 하단 이동 영역의 오른쪽에 다른 단계의 다음 버튼과 같은 크기·색상으로 배치한다.
- 왼쪽에는 기존 `이전` 버튼을 유지한다.

## 제외 범위

- 변경사항 자동 선택
- 비교·병합·감사 로그·DB 저장 규칙 변경
- 단계 순서 변경
- 아티스트 정보 수정 기능

## 예상 수정 파일

- `app/admin/festivals/import-json/StagedFestivalUpdate.tsx`
- `app/admin/festivals/import-json/FestivalUpdateComparisonTable.tsx`
- 관련 테스트
- `PROJECT_STATUS.md`

## 작업 순서

1. 2단계 아티스트 항목 배경을 흰색·테두리 방식으로 변경한다.
2. 비교표의 새 값과 현재 값 열 순서를 바꾼다.
3. 비교표에 전체 반영·전체 유지 이벤트를 연결한다.
4. 4단계에서 선택 0건인 채 다음 단계로 이동할 때 안내한다.
5. 5단계 최종 확정 버튼을 하단 오른쪽으로 이동한다.
6. 타입 검사, ESLint, 관련 비교·선택 테스트를 실행한다.

## 회귀 위험과 검증

- 새 값과 현재 값의 데이터가 열 제목과 뒤바뀌지 않는지 확인한다.
- 전체 반영 후 선택 건수가 표시된 변경 건수와 일치하는지 확인한다.
- 전체 유지 후 선택 건수가 0건인지 확인한다.
- 3단계에서 선택한 기본정보·티켓 항목이 4단계 일괄 선택에 의해 바뀌지 않는지 확인한다.
- 최종 확정 버튼이 기존 `finalize` 동작과 동일하게 실행되는지 확인한다.
- 선택 항목이 없으면 최종 반영 RPC가 실행되지 않는지 확인한다.

## 후속 개선점

- 새 값과 현재 값에서 실제 달라진 단어만 강조하는 기능

## 실제 결과

- 2단계 아티스트 항목의 slate·보라색 배경을 제거하고 흰색 배경과 회색 테두리로 통일했다.
- 3·4단계 비교표의 PC 열과 모바일 표시 순서를 `새 값 → 현재 값`으로 변경했다.
- 타임테이블 표에 `표시된 변경 전체 반영`과 `전체 현재값 유지` 버튼을 추가했다.
- 타임테이블 전체 선택은 기본정보·티켓의 기존 선택 상태를 변경하지 않는다.
- 선택 항목이 전혀 없는 상태에서 4단계를 완료하려 하면 선택 방법을 안내한다.
- 5단계 요약 박스 안의 최종 확정 버튼을 제거하고 하단 오른쪽에 다른 단계 버튼과 같은 형태로 배치했다.
- 시간 변경 감지와 안전 병합 로직은 정상 상태이므로 변경하지 않았다.
- 비증분 타입 검사와 변경 파일 ESLint가 통과했다.
- 비교·병합·감사 요약·전체 선택 관련 테스트 16건이 통과했다.
- localhost 실제 화면 확인은 사용자 환경에서 남아 있다.
