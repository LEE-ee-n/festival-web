# [구현 완료·화면 확인 대기] 공개 상세 무대 미정 제목 숨김

## 목적과 완료 조건

- 공개 축제 상세 출연진에서 무대 정보가 없는 경우 `무대 미정` 제목을 표시하지 않는다.
- 해당 그룹의 아티스트 목록은 그대로 표시한다.
- 실제 무대명이 있으면 기존 무대 제목을 유지한다.

## 확정 범위

- 공개 패널·상세 페이지가 공통으로 사용하는 `StageSchedule` 제목 조건부 표시
- 내부 날짜·무대 그룹 구조와 정렬 규칙 유지

## 제외 범위

- 관리자 라인업 화면의 `무대 미정` 그룹
- DB의 `stage_name` 값 수정
- 날짜 미정·타임테이블 미공개 표시 변경

## 예상 수정 파일

- `components/festival/StageSchedule.tsx`
- 관련 테스트
- `PROJECT_STATUS.md`

## 작업 순서

1. 무대명이 `무대 미정`인 경우 제목 블록만 생략한다.
2. 실제 무대명 제목과 아티스트 목록 렌더링을 유지한다.
3. 타입 검사, ESLint와 전체 테스트를 실행한다.
4. 공개 상세 PC·모바일 화면을 확인한다.

## 회귀 위험과 검증 방법

- 무대 미정 그룹의 아티스트가 함께 사라지지 않는지 확인한다.
- 실제 무대명이 있는 그룹은 아이콘·배경·제목이 그대로인지 확인한다.

## 후속 개선점

- 내부 그룹 키의 표시 문구 의존성을 없앨 필요가 생기면 별도 상수 또는 nullable 그룹 모델로 정리한다.

## 구현 결과

- 공통 `StageSchedule`에서 그룹명이 `무대 미정`이면 무대 제목 블록만 렌더링하지 않는다.
- 해당 그룹의 아티스트 목록과 날짜·시간 정렬은 그대로 유지한다.
- 실제 무대명이 있는 그룹은 기존 아이콘·배경·제목을 유지한다.
- 전체 테스트 164개, 타입 검사와 `StageSchedule.tsx` ESLint가 통과했다.
- 공개 상세 PC·모바일 실제 화면 확인은 남아 있다.
