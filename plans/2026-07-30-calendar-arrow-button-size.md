# 달력 이동 버튼 크기 축소

- 목적: PC 달력의 이전·다음 버튼에서 화살표는 유지하고 원형 테두리만 작게 만든다.
- 범위: `components/calendar/CalendarHeader.tsx`.
- 제외: 모바일 UI, 화살표 글자 크기, 월 이동 동작.
- 검증: 두 버튼이 모두 36px 원형으로 표시되는지 확인한다.

## 완료

- [완료] 이전·다음 버튼을 44px에서 36px로 축소했다.
- [완료] PC 버튼을 월 제목 좌우로 이동하고 원형 크기를 32px로 추가 축소했다.
- [완료] PC 왼쪽 그리드 칸을 빈칸으로 유지해 월 제목과 오른쪽 아이콘 위치를 복구하고 원형을 28px로 축소했다.
- [완료] 원형 테두리·배경·그림자를 제거하고 월 이동 화살표만 표시한다.
