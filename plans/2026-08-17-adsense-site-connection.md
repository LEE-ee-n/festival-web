# [구현 완료] Google AdSense 사이트 연결 계획

## 목적과 완료 조건

- `festibom.com`의 소유권을 AdSense가 확인할 수 있게 연결한다.
- 게시자 ID `ca-pub-1898105658764182`를 공개 검증 정보와 `ads.txt`에 정확히 반영한다.
- 현재 GA4·Clarity 동의 흐름과 관리자·마이페이지의 비공개 기능에 영향을 주지 않는다.

## 확정 범위

- 루트 메타데이터에 `google-adsense-account` 검증 태그 추가
- `https://festibom.com/ads.txt`에 Google 판매자 항목 추가
- AdSense 검토용 스크립트와 CSP 허용 도메인 반영
- 공개 사이트 연결 상태와 프로덕션 빌드 검증

## 제외 범위

- 실제 광고 단위와 자동 광고 노출
- 로그인·관리자·마이페이지·페스티봄 일기의 광고 배치
- 광고 수익 최적화와 위치 실험
- Google CMP 설정 자체(AdSense 화면에서 검토 요청 단계에 설정)

## 예상 수정 파일과 흐름

- `app/layout.tsx`: AdSense 계정 검증 메타데이터와 연결 스크립트
- `public/ads.txt`: 게시자 ID가 포함된 공식 판매자 항목
- `next.config.mjs`: AdSense 연결에 필요한 Google 도메인을 Report-Only CSP에 추가
- `tests/`: 게시자 ID와 공개 경로가 유지되는지 최소 회귀 테스트 추가 여부 검토

## 작업 순서

1. Next.js 16 메타데이터·스크립트 지침 확인
2. 계정 메타 태그와 연결 스크립트 추가
3. `ads.txt`와 CSP 도메인 추가
4. 타입 검사·테스트·프로덕션 빌드 실행
5. 배포 후 공개 URL과 AdSense 연결 확인

## 회귀 위험과 검증

- CSP 누락으로 스크립트가 차단될 수 있으므로 응답 헤더와 브라우저 콘솔을 확인한다.
- 광고 스크립트는 사이트 연결 목적으로만 추가하며 실제 광고 영역은 만들지 않는다.
- 관리자·개인 기록 화면에 광고 단위를 추가하지 않았는지 변경 목록을 확인한다.
- `.env`나 비밀키는 사용하지 않는다. 게시자 ID는 공개 식별자다.

## 후속 작업

- AdSense 승인 후 공개 페이지별 광고 위치를 별도 계획으로 설계한다.
- AdSense의 Google CMP를 설정하고 기존 분석 동의 UI와 역할을 정리한다.
- 광고 노출 시 개인정보처리방침에 광고·쿠키·맞춤 광고 내용을 반영한다.

## 실제 반영 결과

- 루트 메타데이터에 `google-adsense-account=ca-pub-1898105658764182`를 추가했다.
- AdSense 공용 스크립트를 `afterInteractive` 방식으로 전체 공개 사이트에 연결했다.
- `public/ads.txt`와 Report-Only CSP 허용 출처를 추가했다.
- 광고 단위는 만들지 않아 현재 화면에는 광고가 노출되지 않는다.
- 전체 테스트 331개, 타입 검사, 변경 파일 ESLint가 통과했다.
- 프로덕션 빌드는 샌드박스에서 `.env.local` 접근이 거부되어 Supabase 환경변수를 읽지 못한 상태로 중단됐다. 코드 컴파일과 빌드 내 TypeScript 검사는 통과했으며, 실제 환경 빌드는 배포 전 다시 확인한다.
