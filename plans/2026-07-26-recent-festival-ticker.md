# 최근 등록 축제 알림바

상태: 코드 구현 완료 · localhost 화면 확인 대기

## 목적과 완료 조건

- 공개 홈페이지의 공통 헤더 바로 아래에 최근 등록 축제를 한 줄로 알린다.
- 최근 7일 이내 등록된 승인 축제만 최신순으로 표시한다.
- 여러 건이면 3초마다 한 줄씩 위로 전환한다.

## 확정 범위

- 왼쪽에 `NEW`, 가운데에 축제명과 등록 안내, 오른쪽에 닫기 버튼을 둔다.
- 알림 문구를 누르면 해당 축제 상세 페이지로 이동한다.
- 닫기는 현재 화면 상태에서만 유지하며 새로고침·재접속 시 다시 표시한다.
- 항목이 한 건이면 움직이지 않고, 없으면 알림바를 표시하지 않는다.
- 모바일의 긴 문구는 한 줄 말줄임 처리한다.

## 제외 범위

- 24시간 숨김과 사용자별 읽음 상태
- 라인업·티켓 수정 알림
- 관리자 알림 작성 화면
- DB와 RLS 변경

## 예상 수정 파일과 흐름

- `components/calendar/RecentFestivalTicker.tsx`: 조회·전환·닫기 UI
- `components/Calendar.tsx`: 홈페이지 달력 위에 알림바 배치
- `app/globals.css`: 위로 전환되는 애니메이션
- `PROJECT_STATUS.md`: 구현 상태 기록
- 공개 RLS가 허용한 `festivals`에서 승인·비취소·최근 7일 데이터를 읽는다.

## 검증

- 변경 파일 ESLint와 TypeScript 검사를 통과한다.
- 0건·1건·여러 건 표시와 3초 전환을 localhost에서 확인한다.
- 닫은 뒤 현재 화면에서 숨고 새로고침하면 다시 표시되는지 확인한다.

## 후속 개선점

- 24시간 숨김
- 감사 로그 기반 라인업·티켓 업데이트 알림
