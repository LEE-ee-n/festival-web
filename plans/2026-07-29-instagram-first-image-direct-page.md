# Instagram 첫 사진 북마클릿 독립 상세 페이지 지원

## 목적과 완료 조건

- 팝업이 없는 Instagram 독립 게시물 상세 페이지에서도 첫 사진을 저장한다.
- `/<계정>/p/<게시물 ID>/` 주소에서도 정확한 게시물 ID로 파일명을 만든다.
- 기존 상세 팝업 저장 방식은 유지한다.

## 확정 범위

- 게시물 영역 탐색 순서: 상세 팝업 → `article` → `main`
- `/p/<ID>`, `/reel/<ID>`, `/<계정>/p/<ID>` 주소 지원
- 설치 안내 문구와 관련 테스트 갱신

## 제외 범위

- 캐러셀 전체 저장
- Instagram 로그인 자동화
- Discord Bot 변경

## 작업 순서

1. 게시물 주소와 독립 상세 영역 탐색을 추가한다.
2. 독립 상세 페이지 테스트를 추가한다.
3. 설치 HTML을 다시 생성한다.
4. 관련 테스트, 린트와 타입 검사를 실행한다.

## 회귀 위험과 검증

- 팝업 방식이 기존처럼 우선 선택되는지 확인한다.
- 프로필 사진처럼 작은 이미지는 기존 크기 제한으로 제외한다.
- 중첩 주소에서도 게시물 ID가 파일명에 포함되는지 확인한다.

## 후속 개선점

- Instagram이 `article` 구조를 다시 변경하면 실제 DOM 기준으로 탐색 범위를 보완한다.

## 현재 결과

- 팝업, `article`, `main` 순서로 게시물 영역을 찾도록 수정했다.
- `/gyeonggimusic/p/DbDN-kdk-DY/` 형태의 주소에서 게시물 ID를 읽도록 수정했다.
- 관련 테스트 5개, 변경 파일 린트와 타입 검사가 통과했다.
- 새 설치 HTML을 생성했으며 사용자의 실제 Instagram 화면 확인이 남아 있다.
