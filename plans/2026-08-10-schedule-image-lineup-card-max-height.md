# [완료] 2026-08-10 일정 이미지 LINEUP 카드 최대 높이

## 목적과 완료 조건

- 시간이 모두 미정인 LINEUP 화면에서 출연진이 1~2명이어도 카드가 세로 공간 전체를 차지하지 않는다.
- 인원이 적으면 정해진 최대 크기로 위에서부터 쌓고, 인원이 많으면 화면 안에 들어오도록 자동 축소한다.
- 선택한 출연진의 강조 크기는 일반 출연진보다 크게 유지한다.

## 권장 크기 규칙

- 일반 카드 최대 높이: `125px`
- 선택 카드 최대 높이: `168px`
- 카드 사이 간격: `12px`
- 필요한 전체 높이가 공간보다 작으면 LINEUP 제목 아래에서부터 촘촘하게 배치한다.
- 필요한 전체 높이가 공간을 넘으면 현재의 `일반 1 : 선택 1.5` 비율로 전체 카드를 함께 축소한다.

예상 결과:

- 선택 1명: 168px 카드 1개
- 선택 2명: 168px 카드 2개와 12px 간격
- 일반 2명: 125px 카드 2개와 12px 간격
- 인원이 많은 경우: 최대 높이를 넘지 않으며 사용 가능한 높이에 맞춰 자동 축소

## 확정 범위와 제외 범위

- 포함: `ScheduleImageUntimedLineup` 카드 높이 계산과 위쪽 정렬
- 포함: 시간 미정만 있는 LINEUP 화면과 혼합 일정 하단 행의 회귀 확인
- 제외: 글자 크기 변경, 색상 변경, DB 데이터 변경
- 제외: 출연진이 매우 많을 때 별도 페이지를 추가하는 기능

## 예상 수정 파일과 작업 순서

- `components/schedule-image/ScheduleImageUntimedLineup.tsx`
  1. 카드별 권장 최대 높이를 계산한다.
  2. 최대 높이 합계가 영역 안에 들어오면 위에서부터 연속 배치한다.
  3. 영역을 넘을 때만 기존 가중치 기준으로 축소한다.
- 필요 시 높이 계산을 순수 함수로 분리하고 테스트를 추가한다.
- 타입 검사, 관련 ESLint와 전체 테스트를 실행한다.
- localhost에서 1명·2명·다수 LINEUP과 혼합 일정 하단을 확인한다.

## 회귀 위험과 검증 방법

- 최대 높이를 적용한 뒤 카드 사이에 기존 할당 공간만큼 큰 빈칸이 생기지 않아야 한다.
- 선택·일반 카드가 섞여도 순서와 크기 차이가 유지되어야 한다.
- 혼합 일정의 작은 시간 미정 영역에서는 기존처럼 영역 안에 맞춰 축소되어야 한다.

## 후속 개선점

- 카드 높이가 최소 가독 높이보다 작아질 정도로 출연진이 많으면 별도 페이지 분리를 후속 검토한다.

## 실제 결과

- 일반 카드 최대 높이 125px, 선택 카드 최대 높이 168px, 카드 간격 12px를 적용했다.
- 적은 인원은 LINEUP 제목 아래에서부터 최대 높이로 연속 배치하고 남은 아래 공간을 비운다.
- 카드가 영역을 넘는 경우에만 일반 1 : 선택 1.5 비율로 함께 축소한다.
- 높이 계산을 `scheduleImageUntimedLayout.ts` 순수 함수로 분리하고 적은 인원·공간 부족 사례 테스트를 추가했다.
- TypeScript 검사, 관련 파일 ESLint, 전체 자동 테스트 260개와 `git diff --check`가 통과했다.
- localhost 페이지 접속은 확인했지만 테스트 브라우저에 로그인 세션이 없어 실제 LINEUP 화면 확인은 남아 있다.
