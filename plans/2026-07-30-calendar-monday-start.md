# [완료] 월요일 시작 달력 전환

## 목적과 완료 조건

- 홈페이지 월간 달력을 월요일 시작, 일요일 끝 순서로 표시한다.
- 토요일과 일요일에 이어지는 축제가 같은 주의 한 줄에서 연결되어 보이게 한다.
- 날짜 선택, 이전·다음 달 날짜 표시, 축제 막대와 토·일 색상이 새 요일 순서에 맞게 동작한다.

## 확정 범위

- 달력 날짜 배열의 시작일을 월요일로 변경
- 요일 머리글을 `월 화 수 목 금 토 일` 순서로 변경
- 토요일은 파란색, 일요일은 빨간색으로 표시
- 월요일 시작 기준의 날짜 배열과 주말 축제 막대 회귀 테스트 추가
- 관련 구조 문서와 프로젝트 현황 갱신

## 제외 범위

- 달력 디자인, 셀 크기, 축제 색상과 최대 표시 줄 수 변경
- 모바일·PC 레이아웃 재설계
- 축제 데이터 또는 DB 변경

## 예상 수정 파일과 데이터 흐름

- `lib/calendar.ts`: 해당 월의 첫 날짜에서 월요일 기준 시작 날짜 계산
- `components/calendar/CalendarWeekdays.tsx`: 요일 순서와 주말 글자색 변경
- `components/calendar/CalendarDayCell.tsx`: 날짜 숫자의 토·일 색상 인덱스 변경
- `tests/calendarSelection.test.ts` 또는 신규 달력 테스트: 월요일 시작 날짜 배열 검증
- `tests/calendarFestivalBar.test.ts`: 토·일 축제가 같은 행에서 이어지는지 검증
- `ARCHITECTURE.md`: 월간 달력의 월요일 시작 규칙 기록
- `PROJECT_STATUS.md`: 승인·진행·완료 상태와 검증 결과 기록

데이터 흐름은 `getCalendarDays`가 월요일부터 42일을 생성하고, `CalendarGrid`가 그 순서대로 7열에 배치하며, `dayIndex % 7`을 사용하는 날짜 색상과 축제 막대 행 계산이 새 순서를 따르는 구조다.

## 회귀 위험과 검증 방법

- 월초의 이전 달 날짜나 월말의 다음 달 날짜가 잘못 배치될 수 있으므로 월요일·일요일에 시작하는 달을 단위 테스트한다.
- 날짜 색상이 평일에 적용될 수 있으므로 토요일·일요일 인덱스를 코드와 화면에서 확인한다.
- 여러 날짜 축제 막대가 일요일을 넘을 때만 다음 행으로 분리되는지 관련 테스트로 확인한다.
- 날짜 선택과 이전·다음 달 이동은 기존 테스트와 타입 검사로 회귀를 확인한다.

## 실제 결과

- 월간 날짜 배열과 요일 머리글을 월요일 시작, 일요일 끝으로 변경했다.
- 토요일은 파란색, 일요일은 빨간색으로 표시하도록 날짜 색상 기준을 맞췄다.
- 토요일부터 일요일까지 이어지는 축제 막대가 같은 행에 표시되고, 월요일까지 이어질 때 다음 행으로 연결되는 테스트를 추가했다.
- 관련 테스트 11개와 전체 테스트 153개, 타입 검사, 변경 파일 ESLint가 통과했다.
- Codex 브라우저 보안 정책이 localhost 접근을 차단해 PC·모바일 실제 화면 확인은 사용자 확인 대기로 남겼다.
