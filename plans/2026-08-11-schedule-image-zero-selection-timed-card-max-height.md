# [완료] 2026-08-11 일정 이미지 선택 없음 허용·시간 카드 최대 높이

## 목적과 완료 조건

- 내 일정에서 공연을 하나도 선택하지 않아도 전체 타임테이블 이미지를 만들 수 있어야 한다.
- 시간 있는 공연이 1개뿐이어도 카드가 세로 공간 전체를 차지하지 않아야 한다.
- 시간 있는 공연이 1개·2개·3개 또는 그 이상이어도 각 카드가 최대 높이를 넘지 않고 남는 세로 공간은 비워둔다.
- 기존 시간 미정 LINEUP 카드와 같은 최대 높이 규칙을 시간 있는 카드에도 적용한다.

## 확정 범위와 제외 범위

- 선택 0개이면 모든 날짜·무대·공연을 일반 카드로 표시한다.
- 선택이 1개 이상이면 기존처럼 선택 공연이 포함된 날짜만 이미지 페이지에 표시한다.
- 시간 있는 선택 카드는 최대 `168px`, 일반 카드는 최대 `125px`로 제한한다.
- 공연 개수와 타임라인 전체 높이에 관계없이 모든 시간 카드에 같은 상한을 적용한다.
- 카드의 시작 위치는 실제 공연 시간을 계속 따른다.
- 시간 미정 LINEUP의 기존 최대 높이와 자동 축소 규칙은 유지한다.
- 공연 데이터 자체가 0개인 축제의 빈 이미지 생성은 제외한다.
- DB와 개인 일정 선택 데이터 구조는 변경하지 않는다.

## 회귀 위험과 검증 방법

- 선택 없음 페이지 누락: 여러 날짜가 모두 날짜 탭에 표시되는지 확인한다.
- 선택 날짜 회귀: 선택이 있을 때 기존처럼 선택된 날짜만 남는지 확인한다.
- 카드 겹침: 최대 높이 적용 후 다음 공연과 겹치지 않는지 확인한다.
- 글자 잘림: `125px`와 `168px` 안에서 시간과 아티스트명이 읽히는지 확인한다.
- 저장 회귀: 선택 0개 상태에서도 PNG 저장 버튼이 동작하는지 확인한다.

## 실제 결과

- 선택한 공연이 0개이면 모든 날짜·무대의 타임테이블 페이지를 일반 카드로 표시한다.
- 선택한 공연이 있으면 기존처럼 선택 공연이 포함된 날짜의 모든 무대 페이지만 표시한다.
- 시간 카드 개수가 1개·2개·3개 이상이어도 선택 카드는 `168px`, 일반 카드는 `125px`를 넘지 않고 남는 공간을 비운다.
- 시간 미정 LINEUP과 시간 카드가 같은 공통 최대 높이 상수를 사용하도록 중복을 제거했다.
- 전체 테스트 302개와 TypeScript 검사가 통과했고 관련 ESLint 오류는 0개다. 기존 로그인 내부 이동 경고 1개는 이번 범위 밖으로 유지했다.
- 로그인된 localhost 121번 화면에서 선택 0개 상태가 전체 타임테이블을 일반 `125px` 카드로 표시하고 PNG 생성 완료 문구를 남기는 것을 확인했다.
- 같은 공연을 1개 선택한 뒤 강조 카드가 `168px`로 표시되는 것을 SVG 속성으로 확인했다.
- 테스트 공연 일정은 삭제했고 5782 베타 이용권은 원래 `revoked` 상태, 활성 베타 인원은 1명으로 복구했다.
