# [완료] 2026-08-10 일정 이미지 스티커 선택 해제

## 목적과 완료 조건

- 일정 이미지에서 선택한 스티커 밖의 빈 영역이나 일정 칸을 누르면 선택 테두리가 해제된다.
- 스티커 선택·이동·크기 조절·회전 동작은 그대로 유지된다.

## 확정 범위와 제외 범위

- 포함: 일정 이미지 SVG 캔버스의 바깥 클릭 선택 해제 처리와 관련 회귀 검증
- 제외: 스티커 추가·삭제 UI, 저장 이미지 형식, 일정 카드 디자인 변경

## 예상 수정 파일·데이터 흐름

- `components/schedule-image/ScheduleImageCanvas.tsx`
  - 캔버스 포인터 입력 시 선택 ID를 `null`로 변경한다.
- `components/schedule-image/ScheduleImageStickerLayer.tsx`
  - 기존 스티커 조작 이벤트가 캔버스까지 전달되지 않는지 확인하고 필요한 경우 보완한다.
- DB와 저장 데이터 구조는 변경하지 않는다.

## 작업 순서

1. 캔버스와 스티커의 포인터 이벤트 경계를 수정한다.
2. 관련 타입 검사와 ESLint를 실행한다.
3. 가능하면 localhost에서 클릭·드래그·크기 조절·회전을 확인한다.

## 회귀 위험과 검증 방법

- 스티커를 누르는 순간 선택이 다시 해제되거나 드래그가 끊길 수 있다.
- 스티커 선택 유지, 빈 영역·일정 칸 클릭 해제, 이동·크기 조절·회전을 각각 확인한다.
- 모바일 터치도 같은 포인터 이벤트를 사용하므로 타입 검사와 실제 터치 확인 대상을 함께 기록한다.

## 후속 개선점

- 필요하면 키보드 `Escape` 선택 해제와 접근성 안내를 별도 작업으로 검토한다.

## 실제 결과

- 일정 이미지 SVG를 누르면 선택 ID를 `null`로 변경하도록 구현했다.
- 스티커 이동·크기 조절·회전은 기존 `stopPropagation()` 경계를 유지하므로 스티커 조작 중에는 선택이 해제되지 않는다.
- TypeScript 검사, 관련 파일 ESLint, 전체 자동 테스트 258개와 `git diff --check`가 통과했다.
- 2026-08-11 로그인된 localhost 97번 일정 이미지에서 스티커 추가·선택 후 다른 타임테이블 칸을 클릭하면 선택 안내와 삭제 버튼이 사라지는 것을 실제 확인했다.
