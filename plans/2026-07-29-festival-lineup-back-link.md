# 페스티벌 관리 돌아가기 링크

## 목적과 완료 조건

- 개별 페스티벌 관리 페이지 상단에 기존 관리자 돌아가기 링크와 동일한 디자인을 표시한다.
- 클릭하면 `/admin/festivals`로 이동한다.

## 범위

- 공통 돌아가기 링크에 이동 주소와 문구 선택값을 추가한다.
- 개별 페스티벌 관리 페이지에서 공통 링크를 사용한다.
- 다른 화면의 기존 링크 모양과 동작은 유지한다.

## 검증

- ESLint와 TypeScript 검사를 실행한다.

## 결과

- [완료] 기존 공통 링크와 같은 글자색·굵기·호버 스타일을 적용했다.
- [완료] `/admin/festivals`로 이동하는 `← 페스티벌 관리로 돌아가기` 링크를 추가했다.
- [완료] ESLint와 TypeScript 검사를 통과했다.
