# 공개 아티스트 탐색 페이지

## 목표

검색 결과에 의존하지 않고 `/artists`에서 아티스트 상세페이지로 바로 이동한다.

## 확정 사항

- 세로 목록형으로 표시한다.
- 행은 아티스트 이름, 로고, 좋아요 하트 순서로 배치한다.
- 로고가 없으면 같은 크기의 빈 공간을 유지한다.
- 기본 정렬은 숫자, 한글 가나다, 영문 A-Z 순서다.
- 이름 검색과 한글 초성·영문 알파벳·숫자 빠른 필터를 제공한다.
- 좋아하는 아티스트만 보기 필터를 제공한다.
- 비로그인 사용자가 하트를 누르면 로그인 페이지로 이동한다.
- 행 이름을 누르면 기존 `/artist/[id]` 상세페이지로 이동한다.

## 구현 구조

- `app/artists/page.tsx`: 공개 페이지와 메타데이터
- `lib/artists/getPublicArtistDirectory.ts`: 공개 아티스트 전체 조회
- `lib/artists/artistDirectory.ts`: 정렬·검색·빠른 필터 공통 로직
- `lib/hooks/useArtistDirectoryFavorites.ts`: 로그인·찜 목록 일괄 관리
- `components/artists/*`: 필터, 목록, 행 UI

## 제외 범위

- 공통 헤더의 진입 버튼 위치는 별도로 결정한다.
- 관리자 아티스트 데이터 수정 기능은 추가하지 않는다.

## 구현 결과

- 공개 아티스트를 1,000개 단위로 조회해 향후 목록 증가에도 대응했다.
- 숫자·한글·영문 정렬과 검색·초성·알파벳·좋아요 필터를 구현했다.
- 목록 행은 이름·로고·하트 순서이며 로고가 없을 때 빈 공간을 유지한다.
- 찜 상태는 행마다 요청하지 않고 목록 전체에서 한 번만 조회한다.
- 비로그인 하트와 좋아요 필터는 로그인 후 `/artists`로 복귀한다.
- `/artists`를 sitemap 정적 경로에 추가했다.
- 목록 외곽 박스와 좌우 세로선을 제거하고 행 구분선만 유지했다.
- 초성·알파벳·좋아요 필터를 테두리 없는 글자형으로 축소했다.
- 필터 결과는 페이지당 50명씩 표시한다.
- 이전·다음 이동 UI는 공용 `Pagination` 컴포넌트로 분리해 다른 목록에서도 재사용할 수 있다.
- `/artists?page=2` 형식의 실제 링크로 페이지를 이동해 검색엔진도 모든 아티스트 내부 링크를 탐색할 수 있다.
- TypeScript, 관련 ESLint, 전체 테스트 252개가 통과했다.
- localhost PC·모바일 실제 화면 확인과 공통 진입 버튼 위치 결정이 남아 있다.
