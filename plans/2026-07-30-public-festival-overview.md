# 전체 페스티벌 보기

## 목적과 완료 조건

- `/festivals`에서 공개 페스티벌을 이미지 카드 목록으로 본다.
- `전체(개수)`, `예정(개수)`, `진행중(개수)`, `종료(개수)` 필터를 제공한다.
- 카드에도 현재 상태를 표시하고 누르면 해당 페스티벌 상세로 이동한다.
- 달력 상단의 전체보기 아이콘으로 페이지에 진입한다.

## 판정 규칙

- 취소된 축제와 승인되지 않은 축제는 조회하지 않는다.
- 오늘이 시작일 전이면 `예정`, 시작일과 종료일 사이면 `진행중`, 종료일 후면 `종료`다.
- 상태는 날짜로 계산하여 DB 상태를 매일 수동 변경하지 않는다.

## 색상·타이포그래피

- 전체·예정·진행중·종료 필터는 모두 흰색 배경과 공통 브랜드 색상 `festival-night` 글자로 통일한다.
- 선택 상태는 새로운 색을 추가하지 않고 테두리 진하기로만 구분한다.
- 카드 상태 배지도 파랑·초록 배경을 사용하지 않고 흰색·`festival-night`로 통일한다.
- 글자 크기와 굵기는 `lib/typography.ts`의 공통 타입을 사용한다.

## 범위와 제외 범위

- 포함: 공개 목록 페이지, 상태 필터와 개수, 카드, 달력 상단 진입 링크
- 제외: 관리자 페이지, DB 스키마 변경, 페이지네이션
