# [완료] 공개 상세 페이지 흰색 레이아웃 개편

## 목적과 완료 조건

- 독립된 축제 상세와 아티스트 상세 페이지의 배경을 흰색으로 통일한다.
- 축제 라인업을 개별 카드 대신 행 구분선 중심으로 표시한다.
- 티켓·프로그램 영역의 회색 배경을 제거한다.
- 아티스트 상세의 축제 카드 호버는 색상 변경 없이 그림자로만 표시한다.

## 확정 범위

- `/festival/[id]`, `/artist/[id]`의 기본·로딩·오류 화면 배경을 흰색으로 변경한다.
- 축제 상세 라인업의 무대별 바깥 테두리는 유지한다.
- 무대 묶음의 회색 배경과 가수별 흰색 카드 모양을 제거한다.
- 무대 바깥의 둥근 표 테두리는 제거하고 무대명만 사이드 상세보기와 같은 둥근 헤더로 표시한다.
- 가수 행은 사진처럼 행 사이의 선으로 구분한다.
- 가수명과 시간은 달력 옆 상세 패널과 같은 크기·굵기를 사용한다.
- 시간은 브랜드 색상 `festival-purple`을 사용한다.
- 티켓·프로그램 카드의 회색 배경을 흰색으로 변경한다.
- 아티스트 상세의 축제 카드에서 호버 배경색과 테두리색 변경을 제거하고 그림자만 추가한다.
- 축제 상세의 가수명과 시간이 PC에서 양 끝으로 벌어지지 않도록 가수명은 왼쪽 24px, 시간은 고정된 두 번째 열에 표시한다.
- 공연 날짜는 `festival-night` 배경의 둥근 배지로 표시한다.
- 무대명은 `festival-indigo/10` 배경과 `festival-indigo` 글자로 표시한다.
- 최종 무대명·날짜 색상, 아이콘, 글자 크기와 세로 여백은 사이드 상세보기 공통 컴포넌트를 기준으로 사용한다.
- `축제 소개`는 기본정보와 같은 회색 라벨과 진한 값 글자 체계를 사용한다.
- `프로그램`도 `축제 소개`와 같은 라벨·값 글자 체계를 사용한다.
- 공개된 출연진은 사이드 상세보기의 `FestivalTimetable` 전체 컴포넌트를 재사용한다.

## 제외 범위

- 달력 옆 축제 상세 패널 디자인
- 데이터 조회와 저장 흐름
- 관리자 화면
- 상세 페이지의 정보 구조와 표시 순서

## 예상 수정 파일

- `app/festival/[id]/page.tsx`
- `app/artist/[id]/page.tsx`
- 필요 시 `lib/typography.ts`
- `PROJECT_STATUS.md`

## 작업 순서

1. 두 상세 페이지의 모든 상태 배경을 흰색으로 변경한다.
2. 축제 라인업의 무대 묶음은 테두리만 남기고 가수 행을 구분선 구조로 바꾼다.
3. 가수명·시간을 기존 공통 타이포그래피에 연결하고 시간에 브랜드 보라색을 적용한다.
4. 티켓·프로그램 영역의 회색 배경을 제거한다.
5. 아티스트 축제 카드의 호버를 그림자만 표시하도록 변경한다.
6. PC는 왼쪽 24px부터 가수명 180px·간격 24px·시간 자동 너비의 두 열을 배치하고, 모바일은 전체 너비 두 열을 유지한다.
7. 날짜 배지와 무대명에 확정된 브랜드 색상을 적용한다.
8. 타입 검사, 변경 파일 ESLint와 테스트를 실행한다.
9. localhost의 두 상세 페이지에서 PC·모바일 화면을 확인한다.

## 회귀 위험과 검증

- 긴 아티스트명과 시간이 겹칠 수 있으므로 좁은 화면 줄바꿈을 확인한다.
- 첫 행 또는 마지막 행에 불필요한 선이 생기지 않는지 확인한다.
- 시간 없는 가수 행의 정렬을 확인한다.
- 티켓·프로그램 영역의 흰색 배경에서 테두리 구분이 유지되는지 확인한다.
- localhost 브라우저 접근이 차단되면 화면 확인은 사용자 확인 대기로 명시한다.

## 후속 개선점

- 화면 확인 후 행 높이와 좌우 여백을 필요한 경우 별도 조정한다.

## 실제 결과

- 축제 상세와 아티스트 상세의 기본·로딩·오류 화면 배경을 흰색으로 변경했다.
- 축제 라인업은 무대별 바깥 테두리를 유지하고, 무대 배경과 가수별 카드 모양을 제거했다.
- 가수 행을 선으로 구분하고 가수명·시간을 달력 옆 상세 패널과 같은 글자 체계로 맞췄다.
- 공연 시간은 브랜드 색상 `festival-purple`로 변경했다.
- 티켓 영역의 회색 배경을 흰색으로 변경했다. 프로그램 영역은 원래 별도 배경이 없어 흰색 상태를 유지했다.
- 아티스트 상세의 축제 카드는 호버 배경색과 테두리색 변경을 제거하고 그림자만 표시한다.
- 축제 상세 라인업은 모바일에서 전체 너비 두 열을 사용하고, PC에서는 왼쪽 24px부터 가수명 180px과 시간 자동 너비의 두 열을 표시한다.
- 공연 날짜와 무대명은 사이드 상세보기의 색상과 아이콘을 그대로 사용한다.
- `StageSchedule`과 `ArtistScheduleRow`를 공통 사용해 무대명 14px, 세로 여백과 행 구분선을 동일하게 맞췄다.
- `축제 소개`는 기본정보와 같은 회색 라벨과 진한 값 스타일로 변경했다.
- `프로그램`도 기본정보와 같은 회색 라벨과 진한 값 스타일로 변경했다.
- 타임테이블 공개 상태의 출연진은 `FestivalTimetable` 전체 공통 컴포넌트를 재사용한다.
