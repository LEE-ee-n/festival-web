# Instagram 캐러셀 전체 이미지 수집

## 목적과 완료 조건

- Discord Instagram 봇이 캐러셀 게시물의 마지막 슬라이드까지 확인한다.
- 현재 화면에 미리 렌더링된 약 3장만 수집하는 문제를 제거한다.
- 다음 버튼이 사라지거나 5장을 수집하면 정상 종료하고, 중복 이미지와 무한 반복을 방지한다.

## 범위

- 수정: `operations/discord-instagram-bot/src/bot.js`
- 추가: 캐러셀 이미지 URL 누적, 다음 버튼 클릭, 슬라이드 변경 대기, 수집 로그
- 제외: OCR 프롬프트와 DB 저장 구조 변경

## 작업 순서

1. 게시물 영역에서 현재 보이는 큰 이미지 URL을 수집한다.
2. `button[aria-label="다음"]` 또는 영어 `Next` 버튼을 찾는다.
3. 다음 버튼을 누르고 이미지 집합이 변경될 때까지 기다린다.
4. 버튼이 없어지거나 이미지가 반복되거나 5장을 수집하면 종료한다.
5. 누적된 전체 이미지를 기존 다운로드·Codex 분석 과정에 전달한다.

## 위험과 검증

- 인스타 UI 변경에 대비해 동적 클래스명은 사용하지 않는다.
- 최대 5장 제한과 동일 상태 반복 감지로 무한 루프를 막는다.
- 구문 검사와 봇 테스트를 실행한다.
- 실제 게시물 `DbNVeWiESYA`는 봇 재시작 후 마지막 타임테이블 이미지가 포함되는지 사용자가 확인한다.

## 후속 개선

- 동영상 슬라이드의 포스터 또는 프레임 수집은 별도 작업으로 남긴다.

## 완료 결과

- [완료] 실제 확인한 `button[aria-label="다음"]`을 사용해 마지막 슬라이드까지 이동한다.
- [완료] 현재 화면에서 가장 크게 노출된 이미지 URL을 슬라이드별로 누적한다.
- [완료] 중복 제거, 최대 5장 제한, 이미지 미변경 시 종료 처리를 추가했다.
- [완료] 다음 버튼 탐색을 현재 봇의 Puppeteer API(`page.$$`)에 맞췄다.
- [완료] 실제 Instagram DOM에 맞춰 다음 버튼의 `article` 하위 조건을 제거했다.
- [완료] 이미지 탐색과 슬라이드 변경 감지를 `dialog → article → main` 범위로 통일했다.
- [완료] 구문 검사와 Discord Bot 테스트 13개를 통과했다.
