# [구현 완료·화면 확인 필요] 공개 안내·정책·제보 페이지

## 목적과 완료 조건

- 푸터의 공지사항·이용약관·개인정보처리방침·정보 수정 제보 링크가 실제 페이지로 연결된다.
- 네 페이지가 공개 화면의 흰색·회색 디자인과 모바일 레이아웃을 공유한다.
- 개인정보처리방침은 현재 사이트가 실제 처리하는 정보만 기재한다.

## 확정 범위

- `/notices`: 베타 운영 안내 1건과 향후 공지를 추가할 수 있는 목록
- `/terms`: 서비스 성격, 정보 정확성, 이용 제한, 권리, 서비스 변경, 문의
- `/privacy`: 처리 목적·항목·보유기간·파기·제3자 제공·처리위탁·이용자 권리·문의
- `/report`: 제보 작성 안내와 내용이 미리 채워지는 이메일 전송 버튼
- 푸터의 정보 수정 제보 링크를 `mailto:`에서 `/report`로 변경
- 공통 페이지 레이아웃을 재사용

## 현재 개인정보 처리 기준

- 일반 회원가입과 공개 사용자 입력 폼은 없음
- 공개 화면에 별도 분석 도구는 확인되지 않음
- 이메일 제보 시 발신 이메일, 제보 내용과 사용자가 첨부한 자료를 처리할 수 있음
- 관리자 로그인은 운영자 전용이며 공개 이용자 정책과 분리해 설명

## 제외 범위

- DB 제보 저장, 파일 직접 업로드, CAPTCHA, 제보 처리상태 조회
- 공지사항 관리자 작성 기능
- 이메일 외 별도 고객지원 시스템

## 작업 순서

1. [완료] 공통 페이지 레이아웃 작성
2. [완료] 네 페이지 내용 작성
3. [완료] 푸터와 사이트맵 연결
4. [완료] 린트·테스트·타입 검사
5. [대기] localhost PC·모바일 화면과 이메일 실행 확인

## 회귀 위험과 검증

- 긴 정책 문구의 모바일 가로 넘침 여부 확인
- 존재하지 않는 링크와 이메일 제목·본문 인코딩 확인
- `/admin` 푸터 제외 유지 확인
- 개인정보 문구가 실제 구현과 어긋나지 않는지 확인

## 후속 개선점

- 제보량이 많아지면 DB 폼, 스팸 방지, 관리자 처리상태 기능을 별도 계획으로 추가

## 실제 결과

- 사용자 원문의 베타 오픈 공지 내용과 `의견 및 정보 수정 제보` 표현을 유지했다.
- 이용약관에서 아직 제공하지 않는 회원·댓글·기록·유료 기능 조항을 제거했다.
- 자동수집 금지 조항에서 robots.txt를 준수하는 일반 검색엔진을 제외했다.
- 개인정보처리방침을 현재 이메일 제보, Vercel, Supabase와 Gmail 기준으로 정리했다.
- 린트, 타입 검사와 전체 테스트 138건이 통과했다.
- 실제 화면 확인은 사용자가 실행 중인 localhost에서 확인해야 한다.
