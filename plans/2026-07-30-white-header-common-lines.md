# 흰색 공통 헤더·구분선

## 목적과 완료 조건

- 로고·관리자·로그아웃이 있는 상단 헤더를 기본 흰색 배경으로 변경한다.
- 헤더 아래에 공통 연한 구분선을 표시한다.
- 화면별로 섞인 중립 구분선 색상을 공통 `line` 색상으로 통일한다.

## 공통 구분선

- `line-subtle`: `#F0F0F0`
- `line`: `#E5E5E5`
- `line-strong`: `#D4D4D4`

## 범위

- slate/gray 100 테두리 → `line-subtle`
- slate/gray 200 테두리 → `line`
- slate/gray 300·400 테두리 → `line-strong`
- 오류·성공·경고·브랜드 테두리는 유지한다.

## 검증

- 중립 연한 테두리 잔여 항목 검색
- ESLint, TypeScript, 전체 테스트

## 결과

- [완료] 공통 헤더를 흰색 배경과 `ink` 글자색으로 변경
- [완료] 헤더 아래에 `border-line` 구분선 적용
- [완료] slate·gray 100~400 중립 테두리를 `line` 3단계로 통일
- [완료] 기존 중립 연한 테두리 잔여 0건 확인
