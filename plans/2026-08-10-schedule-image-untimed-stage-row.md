# [완료] 2026-08-10 일정 이미지 시간 미정 무대별 배치

## 목적과 완료 조건

- 시간이 정해진 마지막 공연 아래에 `시간 미정` 행을 표시한다.
- 시간 미정 출연진을 각자의 `stageName`에 해당하는 무대 열에 카드로 배치한다.
- 예시로 `타이거 디스코`는 `TINY DISCO` 열의 시간 미정 행에 표시된다.

## 확정 범위와 제외 범위

- 포함: 시간 지정·미지정 공연이 섞인 일정 이미지의 하단 배치
- 포함: 같은 무대에 시간 미정 출연진이 여러 명일 때 해당 열 안에서 나누어 표시
- 제외: DB 데이터 수정, 무대명 자동 보정, 시간 미정 공연만 있는 페이지의 기존 전체 라인업 배치 변경

## 원인과 예상 수정 파일

- 원인: `ScheduleImageCanvas`가 혼합 일정의 시간 미정 항목을 `stageName` 없이 이름 한 줄로 합쳐 출력하고 있다.
- `components/schedule-image/ScheduleImageCanvas.tsx`
  - 마지막 시간선 아래에 시간 미정 행을 만들고 무대별 항목을 분리한다.
- `components/schedule-image/ScheduleImageUntimedLineup.tsx`
  - 기존 카드 배치 컴포넌트를 재사용하며 필요한 표시 간격만 보완한다.
- 필요 시 `tests/scheduleImageLayout.test.ts`
  - 시간 미정 항목의 무대·페이지 보존을 검증한다.

## 작업 순서

1. 혼합 일정의 시간 미정 한 줄 텍스트를 무대별 카드 행으로 교체한다.
2. 마지막 시간선, 시간 미정 라벨, 카드와 하단 브랜드 영역의 간격을 맞춘다.
3. 타입 검사, 관련 ESLint와 자동 테스트를 실행한다.
4. 가능하면 localhost에서 97번 축제 화면을 확인한다.

## 회귀 위험과 검증 방법

- 무대가 여러 페이지로 나뉠 때 다른 페이지의 출연진이 섞이지 않아야 한다.
- 같은 무대의 시간 미정 출연진이 여러 명이어도 카드가 겹치지 않아야 한다.
- 시간 미정이 없는 페이지와 시간 미정만 있는 페이지의 기존 배치를 유지한다.

## 후속 개선점

- 시간 미정 출연진이 매우 많을 때 별도 페이지로 넘기는 기준은 실제 데이터 사례가 생기면 별도 검토한다.

## 실제 결과

- 혼합 일정의 마지막 시간선 아래에 `시간 미정` 행을 만들었다.
- 시간 미정 출연진을 현재 페이지의 `stageName`별로 필터링해 해당 무대 열에 카드로 표시하도록 변경했다.
- 같은 무대의 시간 미정 출연진은 기존 카드 배치 컴포넌트가 열 안에서 높이를 나누어 표시한다.
- TypeScript 검사, 관련 파일 ESLint, 전체 자동 테스트 258개와 `git diff --check`가 통과했다.
- 2026-08-11 로그인된 localhost 97번 화면에서 `타이거 디스코`가 마지막 시간선 아래 `TINY DISCO` 열에 배치되는 것을 실제 확인했다.
