# [완료] 아티스트 프로필 카드 레이아웃

## 목적과 완료 조건

- 아티스트 상세 상단을 독립된 프로필 카드로 분리한다.
- 회색 `아티스트` 문구는 제거하고 이름만 표시한다.
- 오른쪽에는 `image_url`이 있을 때만 정사각형 이미지를 표시한다.
- 이름 아래에는 향후 Instagram·관심 아티스트 기능을 넣을 공간을 남긴다.
- 기존 `출연 페스티벌` 목록과 동작은 유지한다.

## 확정 범위

- `app/artist/[id]/page.tsx`의 공개 아티스트 상세 상단 레이아웃
- PC·모바일에서 긴 이름과 선택적 이미지가 깨지지 않는 반응형 배치

## 제외 범위

- DB·SQL·아티스트 이미지 등록 기능
- Instagram 및 관심 아티스트 저장 기능
- 출연 페스티벌 목록의 데이터·표시 방식 변경

## 작업 순서

1. 기존 상단과 출연 페스티벌 영역을 별도 카드로 분리한다.
2. 기존 `artists.image_url`이 있을 때만 이미지를 표시한다.
3. 이름 아래에 후속 기능용 여백을 둔다.
4. 린트와 타입 검사를 실행한다.

## 회귀 위험과 검증

- 이미지가 없을 때 빈 이미지 틀이 남지 않는지 확인한다.
- 긴 아티스트 이름과 모바일 너비에서 카드가 넘치지 않는지 확인한다.
- 출연 페스티벌 링크와 정보가 기존대로 표시되는지 확인한다.

## 후속 개선점

- 아티스트 관리에서 대표 이미지 URL을 등록·수정하는 기능
- Instagram 링크와 관심 아티스트 저장 기능

## 실제 결과

- 아티스트 이름과 선택적 이미지를 별도 프로필 카드로 분리했다.
- 이미지가 없을 때는 빈 이미지 영역을 표시하지 않는다.
- 출연 페스티벌 목록은 별도 카드로 분리하되 기존 내용과 링크를 유지했다.
- `npm run lint`, `npm run typecheck`가 통과했다.
