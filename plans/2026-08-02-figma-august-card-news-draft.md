# [완료] Figma 8월 카드뉴스 초안 생성

## 목적과 완료 조건

- Figma 데스크톱에서 실행하는 개발용 플러그인으로 2026년 8월 Festibom 데이터를 카드뉴스 초안으로 생성한다.
- 사용자가 정리한 `cover_template`, `festival_card_template`, `festival_list_template`, `closing_template`를 복제하고, 이름이 지정된 레이어에 데이터만 넣는다.
- 생성 결과를 사용자가 Figma에서 검수한 뒤 직접 게시한다.

## 확정 범위

- 대상 기간: 2026년 8월.
- 공개 가능한 Festibom 축제 데이터를 별도 읽기 전용 API로 제공한다.
- 표지 1장, 포스터가 있는 축제별 카드, 남은 축제를 3개씩 묶은 목록 카드, 마무리 카드 1장을 생성한다.
- 축제 카드에는 축제명·기간·장소·예매처·출연진·포스터·캘린더 색상을 채운다.
- 표지 배경은 자동 교체하지 않고 기존 템플릿 이미지를 유지한다.

## 제외 범위

- Instagram 게시, Figma 파일 자동 배포, 게시 문구 작성은 포함하지 않는다.
- 템플릿의 고정 디자인·글꼴·레이아웃 변경은 하지 않는다.
- 관리자 수정 권한이나 비공개 데이터를 Figma에 제공하지 않는다.

## 예상 수정과 흐름

1. Festibom: 카드뉴스 전용 공개 읽기 API와 데이터 변환 함수·테스트를 추가한다.
2. Figma 플러그인: 템플릿을 찾고 복제한 뒤, 명명된 레이어에 API 데이터를 반영한다.
3. 플러그인 실행 UI에서 2026년 8월 생성을 실행하고 결과 수·누락 정보를 보여 준다.

## 작업 순서

1. 8월 대상·표시 문구 변환 규칙을 테스트로 고정한다.
2. 읽기 전용 API와 플러그인 소스·개발용 설치 안내를 작성한다.
3. 템플릿 복제·텍스트/이미지/색상 반영을 구현한다.
4. 단위 테스트·타입 검사·린트로 검증하고, 사용자가 Figma에서 실제 생성 결과를 확인한다.

## 위험과 검증

- 템플릿 레이어 이름이 달라지면 해당 필드만 비어 있을 수 있으므로 생성 전 필수 레이어를 검사하고 오류로 안내한다.
- 이미지 URL 접근 실패 시 오류를 표시하고 원본 템플릿은 변경하지 않는다. 이미 생성된 초안 복제본은 사용자가 확인 후 삭제한다.
- 공개 API는 공개 상세에 이미 노출되는 정보만 반환하는지 테스트한다.

## 후속 개선점

- 기간 선택 UI와 월별 재생성.
- 생성 대상을 직접 선택하는 UI.
- 게시용 캡션 초안 생성.

## 실제 결과

- `GET /api/figma/card-news?year=2026&month=8`이 승인된 8월 축제의 공개 정보만 카드뉴스 형식으로 반환한다.
- Figma 개발용 플러그인이 네 가지 템플릿을 복제해 텍스트·포스터·색상을 반영하고, 생성본을 템플릿 오른쪽에 배치한다.
- 개발용 manifest를 Figma에서 빌드 도구 없이 직접 불러오는 방식에 맞춰 실행 UI를 플러그인 코드 안에 포함했다.
- 텍스트 레이어에 여러 글꼴 스타일이 섞여 있어도 사용 중인 글꼴을 모두 불러온 뒤 내용을 교체하도록 보정했다.
- Figma가 Supabase Storage의 공개 포스터를 다운로드할 수 있도록 프로젝트 Storage 도메인을 명시적으로 허용했다.
- Figma가 WebP 바이트를 직접 이미지로 만들 수 없어 플러그인 UI에서 PNG로 변환한 뒤 포스터 레이어에 적용하도록 보정했다.
- 축제 카드의 라벨과 값 레이어를 분리해 `date_value`, `location_value`, `ticket_platform_value`, `lineup_value`에만 데이터를 넣고, 생성 중 실패하면 해당 실행에서 만든 복제본을 자동 정리하도록 보정했다.
- 전체 테스트 186개, 타입 검사, 변경 파일 ESLint와 플러그인 JavaScript 구문 검사를 통과했다.
- 프로덕션 배포와 Figma Desktop 실제 생성 검증은 사용자가 진행한다.
