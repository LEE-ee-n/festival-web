# [구현 완료·화면 확인 대기] NEW 배지·캘린더 막대 글자 브랜드 색상 통일

## 목적과 완료 조건

- 최근 등록 알림의 `NEW` 배지에서 붉은색을 제거한다.
- 캘린더 파스텔 막대의 축제명을 현재보다 더 진하게 표시한다.
- PC 캘린더 막대에서 위로 치우쳐 보이는 축제명만 시각적 중앙에 맞춘다.
- 모바일에서 오늘 날짜를 표시하는 검정 원을 숫자보다 살짝 큰 크기로 줄인다.
- 캘린더 축제 막대의 완전한 캡슐형 양끝을 살짝 둥근 형태로 바꾼다.
- 모바일 캘린더의 세로 스크롤 차단을 해제해 페이지 하단 푸터까지 이동할 수 있게 한다.
- 새 색상 코드를 만들지 않고 기존에 정한 브랜드 색상 이름만 사용한다.

## 확정 범위

- `NEW` 배지: 흰색 `surface` 배경, `festival-night` 테두리와 글자
- 최근 등록 알림 문장도 기본·hover 모두 `festival-night`로 통일
- 캘린더 막대 축제명: `festival-night`
- 캘린더 막대 앞의 원형 표시점은 PC·모바일 모두 삭제
- 축제명에만 PC 구간(`sm`) 1px 아래 위치 보정
- 오늘 날짜 원: 모바일 `18×18px`, PC 기존 `28×28px` 유지
- 축제 막대 시작·종료 모서리: `rounded-full(9999px)` 대신 `rounded-md(6px)`
- 캘린더 그리드 터치 동작: `touch-none` 대신 `touch-pan-y`
- 공통 `PublicFooter`는 이미 모바일에도 렌더링되므로 구조는 유지
- 최근 등록 알림은 기존 별도 컴포넌트 `RecentFestivalTicker` 구조 유지

## 제외 범위

- 알림 문장과 닫기 버튼
- 닫기 버튼
- 파스텔 막대 배경 5색
- 주말 날짜, 선택 날짜 테두리와 다른 화면 색상
- 모바일 막대 축제명 위치
- PC 오늘 날짜 원 크기
- 여러 날짜에 이어지는 막대의 연결 구조

## 예상 수정 파일

- `components/calendar/CalendarDayCell.tsx`

## 작업 순서

1. `NEW` 배지의 `rose-500`과 흰 글자를 브랜드 색상 클래스로 교체한다.
2. 캘린더 막대 글자를 `festival-night`로 교체하고 앞의 표시점을 삭제한다.
3. 축제명에만 PC 구간 1px 아래 위치 보정을 적용한다.
4. 모바일 오늘 날짜 원만 18×18px로 줄이고 날짜 칸의 기존 정렬 위치는 유지한다.
5. 축제 막대 시작·종료 끝부분을 6px 반경으로 변경한다.
6. 캘린더의 모바일 세로 스크롤을 허용하면서 좌우 월 이동 제스처는 유지한다.
7. 관련 ESLint, 타입 검사와 전체 테스트를 실행한다.
8. localhost 실제 화면을 확인한다.

## 회귀 위험과 검증 방법

- 작은 `NEW` 배지에서 검정 테두리와 글자가 선명한지 확인한다.
- 다섯 파스텔 막대 모두에서 축제명이 읽히는지 확인한다.
- PC·모바일 막대에서 표시점이 사라졌는지 확인한다.
- PC 막대에서 축제명이 시각적 중앙에 맞는지 확인한다.
- 모바일 오늘 날짜가 한 자리·두 자리 모두 작은 원 안에서 읽히는지 확인한다.
- PC 오늘 날짜 원은 기존 크기가 유지되는지 확인한다.
- 연속 막대는 중간이 끊기지 않고 시작·종료 끝만 살짝 둥근지 확인한다.
- 모바일에서 캘린더 위로 세로 스크롤해 푸터까지 도달하는지 확인한다.
- 좌우 스와이프로 이전·다음 달 이동이 유지되는지 확인한다.
- 알림 회전·닫기와 캘린더 클릭 동작이 유지되는지 기존 테스트와 화면으로 확인한다.

## 후속 개선점

- 알림 본문 색상까지 브랜드 색상으로 통일할지는 실제 화면 확인 후 별도로 결정한다.

## 구현 결과

- 최근 등록 알림 `NEW` 배지를 `surface` 배경과 `festival-night` 테두리·글자로 변경했다.
- 알림 문장도 기본·hover 모두 `festival-night`로 통일했다.
- 캘린더 막대 앞의 원형 표시점을 삭제하고 축제명을 `festival-night`로 변경했다.
- PC 축제명에만 1px 아래 위치 보정을 적용했다.
- 막대 시작·종료 모서리를 완전한 캡슐형에서 6px 반경으로 변경했다.
- 모바일 오늘 날짜 원은 18×18px로 줄이고 PC의 28×28px 크기는 유지했다.
- 캘린더 그리드의 `touch-none`을 `touch-pan-y`로 변경해 모바일 세로 스크롤을 허용하고 좌우 포인터 스와이프 처리는 유지했다.
- 전체 테스트 162개, 타입 검사와 변경 파일 ESLint가 통과했다.
- localhost 모바일 실제 화면 확인은 남아 있다.
