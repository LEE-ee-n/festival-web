# 프로젝트 반복 명령 단축 파일

상태: 구현 완료

## 목적

- 매번 프로젝트 절대경로와 같은 명령을 다시 입력하지 않게 한다.
- 커밋 메시지만 인자로 받아 Git 커밋과 푸시를 실행한다.
- 한 번의 명령으로 festibom 개발 서버를 실행한다.

## 파일

- `tools/git-push.cmd`
- `tools/localhost.cmd`

## 안전 규칙

- CMD 파일의 위치를 기준으로 festibom 프로젝트 폴더를 찾아 실행한다.
- 커밋 메시지가 없으면 실행하지 않는다.
- 커밋 전에 스테이징된 파일 목록을 출력한다.
- localhost 명령은 기존 `npm run dev`만 실행한다.
