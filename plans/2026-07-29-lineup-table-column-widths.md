# 라인업 관리 표 열 너비 조정

## 목적과 완료 조건

- PC 라인업 표에서 공연 날짜와 시작·종료 시간이 잘리지 않게 한다.
- 아티스트와 무대 열의 과도한 폭을 줄여 날짜·시간 열에 배분한다.
- 모바일 카드 배열은 변경하지 않는다.

## 확정 범위

- 아티스트 `25% → 21%`
- 공연 날짜 `145px → 14%`
- 공연 시간 `210px → 25%`
- 무대 `17%`, 상태 `10%`, 작업 `13%`

## 제외 범위

- 입력값과 저장 로직
- 모바일 레이아웃
- 아티스트 추가 입력 영역

## 작업 순서

1. PC 표의 `colgroup` 너비를 조정한다.
2. 변경 파일 린트와 타입 검사를 실행한다.
3. localhost PC 화면에서 날짜·시간 표시를 확인한다.

사용자 화면 확인 후 공연 날짜 16%가 과도하고 공연 시간이 일부 잘리는 것을 확인해 날짜 14%, 시간 26%로 계획을 수정했다.

추가 화면 확인 후 아티스트 열을 20%로 줄이고 확보한 2%를 무대 열에 배분했다.

최종 미세 조정으로 아티스트 열을 21%, 공연 시간 열을 25%로 변경했다.

## 회귀 위험과 검증

- 긴 아티스트명과 무대명이 자연스럽게 줄바꿈되는지 확인한다.
- 날짜 선택기와 시작·종료 시간이 모두 표시되는지 확인한다.
- 저장·삭제 버튼이 줄바꿈되지 않는지 확인한다.

## 후속 개선점

- 실제 운영 화면 너비에 따라 1~2% 단위로 미세 조정할 수 있다.
