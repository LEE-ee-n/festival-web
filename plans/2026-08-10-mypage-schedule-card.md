# [완료] 마이페이지 내 공연 일정 박스 정렬

## 목적과 완료 조건

마이페이지의 `내 공연 일정` 영역을 위·아래 섹션과 같은 카드형 박스로 감싸 화면의 좌우 시작선과 여백을 통일한다.

## 확정 범위와 제외 범위

- `내 공연 일정` 섹션에 `좋아하는 아티스트`와 동일한 둥근 테두리, 배경, 그림자, 반응형 안쪽 여백을 적용한다.
- 제목, 일정 목록과 구분선이 카드 내부 여백에 맞게 정렬되는지 확인한다.
- 일정 목록의 접기·펼치기 동작과 데이터 구조는 변경하지 않는다.
- 다른 마이페이지 카드의 디자인은 변경하지 않는다.

## 예상 수정 파일·데이터 흐름

- `components/mypage/MyPageContent.tsx`
- 데이터 조회와 저장 흐름은 변경하지 않고 레이아웃 클래스만 수정한다.

## 작업 순서

1. [완료] `내 공연 일정` 섹션을 기존 카드와 같은 스타일로 변경한다.
2. [완료] 기존 일정 목록의 내부 여백과 중복되는 부분이 없는지 코드에서 확인한다.
3. [부분 완료] 타입 검사·관련 린트는 통과했다. localhost PC 화면은 개발 서버의 Supabase 환경변수 미인식 오류로 확인하지 못했다.
4. [완료] 완료 결과를 본 문서와 `PROJECT_STATUS.md`에 반영한다.

## 회귀 위험과 검증 방법

- 위험: 카드 여백과 일정 목록 자체 여백이 겹쳐 내용이 과도하게 안쪽으로 들어갈 수 있다.
  - 검증: 제목과 일정 행의 시작점, 위·아래 카드 시작선을 PC 화면에서 비교한다.
- 위험: 모바일 가로폭에서 일정명이 지나치게 좁아질 수 있다.
  - 검증: 모바일 폭에서 일정명·장소 말줄임과 접기 버튼 배치를 확인한다.

## 실제 결과

- `내 공연 일정` 섹션에 `좋아하는 아티스트`와 동일한 둥근 테두리, 배경, 그림자, `p-6 sm:p-8` 여백을 적용했다.
- 일정 조회, 그룹 접기·펼치기와 행 구성은 변경하지 않았다.
- `npx.cmd eslint components/mypage/MyPageContent.tsx` 통과.
- `npm.cmd run typecheck` 통과.
- 2026-08-11 로그인된 localhost에서 PC·모바일 폭을 다시 확인했다. `내 공연 일정` 카드의 테두리·여백·좌우 시작선이 위·아래 카드와 맞고, 일정명·장소 말줄임과 접기 영역도 깨지지 않았다.
