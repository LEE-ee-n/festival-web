# [완료] 2026-08-05 아티스트 프로필 헤더 세로 중앙 정렬

## 목적과 완료 조건

- 공개 아티스트 상세(`/artist/[id]`) 헤더를 `아티스트명·YouTube·Instagram·추천 플레이리스트 → 로고` 순서로 배치한다.
- 아티스트 정보·버튼 묶음은 오른쪽 로고를 기준으로 세로 중앙에 정렬된다.
- PC와 모바일에서 로고·버튼의 기존 크기와 링크 동작은 유지된다.

## 확정 범위와 제외 범위

- 범위: 공개 아티스트 헤더의 요소 순서와 정렬 CSS를 변경한다.
- 제외: 로고·버튼 크기, 버튼 문구·링크, 데이터·DB, 관리자 화면 변경.

## 예상 수정 파일·데이터 흐름

- `components/artist/ArtistProfileHeader.tsx`: 아티스트 정보·버튼 묶음 오른쪽에 로고를 배치하고, 정보 묶음을 로고 기준 세로 중앙으로 정렬한다.
- `PROJECT_STATUS.md`: 작업 상태를 기록한다.
- 데이터 흐름 변경 없음.

## 작업 순서

1. 헤더 요소를 아티스트 정보·버튼 묶음, 로고 순으로 재배치한다.
2. 아티스트 정보 묶음을 로고와 같은 세로 중앙 기준으로 정렬한다.
3. 타입 검사와 변경 파일 린트를 실행한다.
4. localhost `/artist/2`에서 PC·모바일 화면을 확인한다.

## 회귀 위험과 검증 방법

- 긴 아티스트명 또는 버튼 줄바꿈 때 바로 오른쪽 로고와 겹치지 않는지 확인한다.
- 로고가 없는 아티스트의 기본 아이콘과 외부 링크 동작을 확인한다.

## 후속 개선점

- 실제 화면 확인 후 필요하면 작은 모바일 폭에서 버튼 줄바꿈 간격을 별도 조정한다.

## 실제 결과

- 사용자 예시 기준으로 아티스트명·YouTube·Instagram·추천 플레이리스트 묶음 오른쪽에 로고를 배치했다.
- 헤더의 직접 요소를 세로 중앙 정렬해 아티스트 정보 묶음이 로고 높이를 기준으로 중앙에 위치한다.
- `npm.cmd run lint -- components/artist/ArtistProfileHeader.tsx`와 `npm.cmd run typecheck`가 통과했다.
- 브라우저 정책이 localhost 접속을 차단해 실제 PC·모바일 화면 확인은 남아 있다.
