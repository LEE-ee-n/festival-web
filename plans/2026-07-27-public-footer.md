# 공개 페이지 푸터

## 목적과 완료 조건

- 공개 페이지 아래에 Festibom 안내와 정책·제보 링크를 표시한다.
- 모바일에서 링크와 안내문이 줄바꿈돼도 잘리지 않는다.
- `/admin` 페이지에는 푸터를 표시하지 않는다.

## 범위

- `components/PublicFooter.tsx`
- `app/layout.tsx`
- 공지사항 `/notices`, 이용약관 `/terms`, 개인정보처리방침 `/privacy` 링크를 준비한다.
- 정보 수정 제보와 문의 이메일은 `mailto:`로 연결한다.
- 정책 페이지의 실제 내용 작성은 제외한다.

## 디자인

- 흰색 배경과 상단 1px 연한 회색 구분선
- 최대 너비 1500px 중앙 정렬
- 콘텐츠와 40px 간격, 최소 높이 140px
- 네 개 메뉴 링크를 동일한 회색 텍스트 스타일로 통일
- 모바일 2열 링크 배치, 안내문 자동 줄바꿈
- 링크·문의·안내문·저작권을 가운데 정렬하고 좌우 끝 벌어짐 제거
