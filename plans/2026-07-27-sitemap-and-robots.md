# 사이트맵과 검색로봇 설정

## 목적과 완료 조건

- `https://festibom.com/sitemap.xml`에서 공개 페이지 목록을 제공한다.
- `https://festibom.com/robots.txt`에서 공개 페이지 수집을 허용하고 `/admin`을 차단한다.

## 범위

- `app/sitemap.ts`
- `app/robots.ts`
- 공개 승인된 축제와 공개 라인업에 연결된 아티스트만 사이트맵에 포함한다.
- 관리자 페이지와 검토 중인 데이터는 포함하지 않는다.

## 작업 순서

1. 메인 페이지를 기본 사이트맵 항목으로 추가한다.
2. Supabase 공개 정책을 통과한 승인 축제와 출연 아티스트 URL을 추가한다.
3. DB 조회 실패 시 메인 페이지만 반환한다.
4. robots에서 `/admin`을 차단하고 사이트맵 주소를 알린다.

## 검증

- 린트
- 전체 테스트
- 프로덕션 빌드
- 빌드 결과에 `/sitemap.xml`, `/robots.txt`가 생성되는지 확인

## 완료 결과

- [완료] 공개 승인 축제와 공개 라인업 아티스트를 포함하는 사이트맵을 추가했다.
- [완료] `/admin` 수집을 차단하고 사이트맵 위치를 알리는 robots 설정을 추가했다.
- [완료] 사이트맵은 1시간마다 갱신된다.
- [완료] 린트 통과, 테스트 138개 통과, 프로덕션 빌드에서 두 경로 생성을 확인했다.
