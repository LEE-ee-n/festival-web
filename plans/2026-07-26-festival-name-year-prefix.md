# 페스티벌명 연도 접두어 통일

상태: 구현 및 운영 DB 적용 완료 · 신규 JSON 실사용 확인 대기

## 목적과 완료 조건

- 모든 정식 페스티벌명을 `시작 연도 + 공백 + 축제명` 형식으로 통일한다.
- 연도는 수동 입력값이 아니라 `start_date`에서 결정한다.
- `normalized_name`에는 연도를 포함하지 않아 연도별 히스토리를 묶을 수 있게 한다.

## 확정 범위

- Discord Instagram JSON 생성 프롬프트에 이름 규칙을 추가한다.
- 생성된 JSON을 저장하기 전에 이름을 다시 보정한다.
- DB 쓰기 시 이름을 자동 보정하고 형식을 검사한다.
- 공개 검색의 축제 결과는 최신 시작일순으로 표시한다.

## 제외 범위

- 기존 `normalized_name` 변경
- 축제 히스토리 전용 화면
- 공식 명칭 중간이나 뒤에 포함된 연도 제거

## 작업 순서

1. 현재 DB의 이름 연도와 시작일 연도를 조회한다.
2. JSON 이름 보정 함수를 만들고 테스트한다.
3. 생성 프롬프트와 생성 후 처리에 보정 함수를 연결한다.
4. DB 함수·트리거·제약조건 migration을 작성한다.
5. 관련 테스트와 타입·린트를 실행한다.

## 위험과 검증

- 이름 앞의 `20XX`만 교체하고 이름 중간·뒤의 공식 표기는 보존한다.
- 시작일이 없는 임시 JSON은 이름을 강제로 바꾸지 않는다.
- DB에서는 시작일이 있는 정식 축제만 정확한 연도 접두어를 허용한다.
- migration 적용 전 기존 데이터 조회 결과가 비어 있음을 확인한다.
